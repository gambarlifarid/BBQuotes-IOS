# BBQuotes

An iOS app that fetches quotes, characters, and episodes from the Breaking Bad universe (Breaking Bad, Better Call Saul, El Camino).  
Built with Swift 6 and SwiftUI.

## What it does
- Fetches random quotes and episodes from a Breaking Bad API.
- Displays character information with images, occupations, aliases, and status.
- Shows spoiler-aware death info with images and details.
- Async image loading for character and episode images.
- Tab-based navigation for Breaking Bad, Better Call Saul, and El Camino.
- Uses MVVM with async/await for networking.

## Tech used
- Swift 6 / SwiftUI
- MVVM architecture
- Async/Await networking
- JSON decoding with Codable
- API integration (Breaking Bad API)
- Custom SwiftUI views
